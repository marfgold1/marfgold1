## Code

Use `const` and `=>`, or run `npm run dev`. Ligatures render in `!==`, `>=` and `->`. Inline highlighting works too: `const x: number = 1{:ts}`.

```ts
// read the saved theme, fall back to system
export function getTheme(): string {
  const saved = localStorage.getItem("theme");
  if (saved !== null && saved.length >= 4) return saved;
  return matchMedia("(prefers-color-scheme: dark)").matches
    ? "dark" : "light";
}
```

## Math

Inline math like $e^{i\pi} + 1 = 0$ sits in the text, while display math gets its own line:

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

## Callouts and details

<Callout type="note">Info callouts use indigo and always carry a text label.</Callout>

<Callout type="tip">Tips use teal. Label plus colour, never colour alone.</Callout>

<Callout type="warning">Warnings use amber, which is safe for red-green colour blindness.</Callout>
